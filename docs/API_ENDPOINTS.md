# API endpoints
## Host-side website:
| Route | Explanation | HTTP METHOD |
| --- | --- | --- |
| `/` | Домашняя страница, отображает сам HOST WEB UI | GET |
| `/<path_to_dir>` | Листинг директории по пути | GET |
| `/upload/` | Загружает файл по пути на сервер (располагает файл в временной папке, предназначенной для временного хранения файлов) | POST |
| `/download/<path_to_file>` | Скачивает файл по пути на устройство-хост (под капотом просто перемещает файл на ФС из временной папки) | GET |
| `/accept/` | Принимает запрос на подключение от конкретного пользователя | POST |
| `/deny/` | Отклоняет запрос на подключение от конкретного пользователя | POST |
| `/block/` | Отклоняет запрос на подключение от конкретного пользователя и отправляет его в бан-лист | POST |
| `/trust/` | Принимает запрос на подключение от конкретного пользователя и отправляет его в trusted-лист | POST |

## Client-side website:
| Route | Explanation | HTTP METHOD |
| --- | --- | --- |
| `/` | В случае незарегистрированного пользователя на страницу `/login`, иначе отображает CLIENT WEB UI | GET |
| `/login` | Отправляет запрос на подтверждение пользователя | GET |
| `/upload` | Загружает (для зарегистрированного пользователя) файл в временную папку на хост-сервере | POST |
| `/download` | Скачивает файл (для зарегистрированного пользователя) на локальное устройство | GET |
