# Quick Share 

**Quick Share** — это гибридное решение для быстрого обмена файлами между устройствами в одной локальной сети (Wi-Fi) без доступа к интернету.

## Описание проекта
Проект решает проблему передачи данных в условиях блокировок мессенджеров и отсутствия стабильной сети (например, в университетах). Мы исключаем необходимость использования флешек или облачных хранилищ, обеспечивая прямую передачу данных внутри LAN.

## Ключевые функции

*   **Локальные сессии обмена:** Запуск сервера на устройстве-хосте для  обнаружения и подключения участников в рамках одной сети.
*   **Управление доступом:** Владелец хоста лично подтверждает запросы на подключение от новых пользователей, обеспечивая контроль над тем, кто видит файлы.
*   **Загрузка файлов:** Возможность для любого подтвержденного участника загружать файлы в общую временную папку на хост-сервере.
*   **Мгновенное скачивание:** Участники могут просматривать список всех загруженных в сессию файлов и скачивать нужные объекты напрямую на свои устройства.
*   **Безопасность и конфиденциальность:** 
    *   Шифрование трафика по протоколу **HTTPS**.
    *   **Локальное хранение:** файлы не уходят во внешнюю сеть и остаются строго внутри LAN.
    *   **Автоочистка:** полное удаление всех данных с сервера сразу после завершения сессии.
*   **Кроссплатформенность:** Полноценный веб-интерфейс для любых ОС (через браузер) и нативное мобильное приложение для Android.

##  Технический стек
*   **Backend**: `Rust` + `Docker` (высокая производительность и легкое развертывание).
*   **Frontend (Web)**: `HTML` / `JavaScript` (доступ через любой современный браузер).
*   **Mobile**: `Kotlin` (нативное приложение для Android 8.0+).
*   **Протоколы**: `HTTPS` с самоподписанными сертификатами для защиты локального трафика.
